# DeskPet 桌宠

一只用纯 Java (Swing + Java2D) 手绘的桌面小猫，无需任何图片素材，单文件即可运行。

## 功能

- 在屏幕底部散步，带走路弹跳、尾巴摇摆、随机眨眼等细节动画
- 左键点击：开心冒爱心 + 随机说话气泡
- 双击：打个滚，冒星星
- 摸头：鼠标停在头顶，眯眼享受、脸红、冒小爱心
- 喂小鱼干：鱼干扔在面前，它会自己走过去吃掉
- 拖到半空松手：重力掉落、落地弹跳挤压
- 右键菜单：喂小鱼干 / 去散步 / 打个滚 / 换毛色（橘猫、灰猫、奶牛猫、粉猫）/ 退出
- 随机小动作：伸懒腰、抬爪洗脸
- 45 秒不理它：睡着冒 Zzz
- 启动时按时段问候（早上好呀喵！）

## 运行

需要 JDK 8 及以上：

```bash
javac -encoding UTF-8 DeskPet.java
java DeskPet
```

Windows 下也可以把便携版 JDK 解压到项目的 `.jdk` 文件夹后，直接双击 `启动桌宠.bat`。

## 实现

- 无边框透明置顶窗口，不占用任务栏
- 简单状态机：发呆 / 散步 / 开心 / 睡觉 / 下落 / 进食 / 打滚 / 伸懒腰 / 洗脸
- 所有画面由 Java2D 实时绘制：渐变身体、粒子特效（爱心、星星、Zzz）、说话气泡
